Development

Technologies

CRAB CAKES v2 is a desktop application built with Flutter and Dart. Our team is extending the original CRAB CAKES codebase rather than replacing it with a separate application.

The application uses a local SQLite database to store survey records, so biologists can work without an internet connection. We use fl_chart, a Flutter charting library, to create QA/QC graphs and summaries directly from saved data.

Development also involves Bluetooth PIT-tag scanner communication, testing on Windows and Linux, and improving the field data-entry interface. We use GitHub to collaborate and manage changes to our code.
